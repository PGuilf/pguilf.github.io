Opus 5.5 for animation: is it worth the hype?

Close

I started with a sketch of a few things that were top of mind: a review pill, a "Review submitted" badge and a "Top tour" badge. Rough, but enough to know what each one should do. Then into Figma, really quick. I used the agent to finesse the details, which saved a lot of pixel nudging.

Then into Claude with Opus 5.5. With the Figma MCP connected, I just shared the links and Claude pulled the designs straight from the file. No exporting or rebuilding. I described the motion in plain words: start with the star and avatars, then open up; rise from the bottom, pop, drop back down. It built each one as its own animation and exported MP4s. I gave it our font and a few timing notes, and it re-rendered them. Simple. So, worth the hype? For UI motion like this, yes. It's really effective. No more After Effects.
