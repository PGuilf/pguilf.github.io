Shipping a new portfolio with Claude Code

Back to Journal

The last version of this site worked. Gemini got the structure down, ChatGPT helped with transitions, and I hand-tuned the rest. But it was all chat-based — paste a snippet, copy the fix, start again next session with no memory of what came before. Claude Code changed that.

A different way of working: Claude Code runs inside the project. It reads every file, understands how things connect, and edits directly — no copy-pasting. I could describe a problem in plain English and it would reason through the codebase to fix it. Less like prompting an AI, more like working with someone who actually knows the repo.

Animation without Figma: Small details that would have meant a Figma round-trip — hover states, scroll reveals, the reel carousel, page fade transitions — I just described them in plain English and iterated in the browser. Faster feedback, no back and forth between tools. I decided when each thing felt right; Claude drafted and revised until it did.

The MD file: I kept a markdown file alongside the project — decisions made, things tried, what's next. Drop it in at the start of each session and Claude Code has context that isn't in the code. No re-explaining the site every time. The work has a thread. I wrote more about this approach in Using MD files to document projects.

Shipping fast: Start to shipped in a few days. The structure, the dark mode, the reel, the journal — all of it in short focused sessions. I still made every call: what stays, what goes, when something feels right. Claude Code just closed the gap between the idea and the thing.
